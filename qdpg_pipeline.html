Key Design Decisions

Why arcsin in angle encoding?
PCA output is unbounded. The min-max + arcsin pipeline in PCAWithNormalization bounds every value to [-π/2, π/2] — the valid half-turn range for an RY gate — so no angle ever causes a qubit to wrap around the Bloch sphere unpredictably.
Why radial_to_linear for amplitude encoding?
If a purely linear feature set lies on a hypersphere in Hilbert space, all inputs live on a thin manifold and the circuit sees little variation in amplitudes. Concatenating [X, X², sin(X), cos(X)] breaks that radial symmetry, spreading features across a richer non-radial subspace before normalization encodes them as state amplitudes.
